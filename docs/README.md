# docs/ — memória do projeto DGO+

Esta pasta guarda a memória durável do projeto: decisões, lições aprendidas e o
porquê de cada bloco de entrega. É o que permite retomar o trabalho em um chat
novo sem reconstruir contexto do zero.

| Arquivo | O que é |
|---|---|
| `contexto-dgoplus.md` | Estado atual: ambiente, arquitetura, direitos, lições, blocos fechados |
| `roadmap-dgoplus.md` | O que vem a seguir: blocos abertos, pendências de investigação, dívidas |

**Regra:** os dois documentos são **substituídos**, nunca acumulados. O número de
versão fica no cabeçalho de cada um; o histórico é o próprio Git.

Vale a regra de governança da seção 0 do contexto: **o GitHub é o repositório
canônico do DGO+; a homologação é descartável.**
